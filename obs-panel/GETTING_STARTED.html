PTZ Commander — Getting Started

This is the operator guide that ships with the installer. It is not the project README. Use it after install to put the scene panel in OBS.

What you need

  • PTZ Commander running (Start Menu or the desktop shortcut).
  • A setup loaded in Commander so scenes exist (the REPL setup load command).
  • OBS Studio with Custom Browser Docks (built in; no extra OBS plugin).

Add the dock in OBS

  1. Start PTZ Commander first. Leave it running.
  2. In OBS: Docks → Custom Browser Docks…
  3. Give it a name such as PTZ Commander.
  4. Set the URL to the panel file (default install):

file:///C:/Program Files/PTZCommander/obs-panel/index.html

If you installed somewhere else, use that folder’s obs-panel\index.html instead. Spaces in the path are fine in a file:/// URL; OBS should accept the path as shown.

  1. Apply. Dock the panel wherever you like.

Using it

The dock lists scenes from Commander’s in-memory setup. Click a name to apply it (same as scene apply in the REPL). Status shows Connected when Commander is listening on this PC. Disconnected means Commander is not running; start it and wait, or press Reconnect.

The socket is localhost only. The dock is an HTML file on disk talking to Commander; it is not an OBS plugin DLL.

If the list is empty

Connected with no scenes means nothing is loaded yet. Load a setup in Commander, then the dock updates. If OBS was open before the first install, reload the dock (click it and press Ctrl+R) after you confirm the file path.
